How it works

From "what's out there" to reading the code.

The whole journey — browsing, filtering, searching, and opening a real project — takes about thirty seconds. Here's exactly what that looks like.

1

Open the collection

Land on the tracker and the full catalogue is right there — 40 projects, one glance, no login, no paywall. The header stat chips tell you the shape of the collection at a glance: 16 web apps · 9 AI agents · 13 dev tools · 2 experiments.

The search box and filter pills stay pinned while you scroll, so the whole collection is always one interaction away.

jellydn.github.io/personal-ai
2

Filter to what you care about

Click AI agents and 9 agent projects appear — coding agents, provider plugins, launchers, and memory tools. Click Web apps and you get the products you can actually use today.

Each filter re-renders instantly. There's no separate page to load, no URL to remember — the grid just becomes the answer.

filter: AI agents
3

Search as you type

No "search page" — the filter bar is always live. Start typing local and the grid narrows in real time, matching against names, descriptions, and how each project works.

Watch it happen below: each keystroke cuts the collection down to exactly the projects that matter.

search: "local"
4

Open the repo or try the demo

Every card is a link to the real thing. Click the project name to land on its GitHub repository — the code, the README, the issues, all of it.

Twenty-five projects carry a Demo badge. One click and you're running the actual product: a tiny Pomodoro PWA, PromptBench, or a live project site.

jellydn.github.io/tiny-pomodoro
5

Take it further

Find something you want to build on? Fork it. Spot something missing? The tracker is a living document — new projects land as the exploration continues.

Star the repo, watch the IT Man Channel, or follow @jellydn to see what ships next.

Go try it for real

The tracker is live, free, and open source. Thirty seconds from now you could be reading real AI-built code.
