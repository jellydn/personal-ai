FAQ

Questions, answered.

Straight answers about the tracker, the projects, and what "AI-built" actually means here.

Are the 53 projects really built with AI?

Yes. Every project in the tracker was built with AI assistance during nine months of exploration. Each one is original work — not a fork, not a template — and the full source is public on GitHub.

How do I run or fork a project?

Every card links to its GitHub repository, and projects with live demos include a one-click Demo link. Clone or fork the repo and follow its README to run it locally.

Is the tracker itself open source?

Yes. The tracker and this showcase site are open source on GitHub under jellydn/personal-ai, deployed free on GitHub Pages.

How is the tracker maintained?

The project catalogue is a single data array in the portfolio page. It ships as a buildless static site — no bundler or framework — so adding a project is one edit and deploys are instant.

Can I contribute a project to the list?

The list tracks original work built during AI-assisted exploration. If you have a question about a specific project, the best place to ask is its GitHub repository.

Why are there only 53 projects?

Each entry represents a real, runnable project — quality over quantity. The number grows as new original work is completed.

Does the tracker require any account or payment?

No. It is free, open source, and runs entirely in the browser. There is no account, no login, and no tracking beyond standard static-host analytics.

How is this different from other AI project lists?

Most lists collect links; this is a living catalogue of the author's own original work. Every project is filterable, searchable, has a written description of its approach, and links to real source code.
