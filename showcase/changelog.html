Under the hood

How the tracker stays honest

A few straight answers about where the data comes from and how the site reaches your browser.

Where do the 41 projects come from?

They're curated by the author — real, runnable, open-source projects built over nine months with AI assistance. Each one links to a repository you can fork and run yourself. The README explicitly states that forked repositories are not added, so the catalog only ever contains original work.

How is the site deployed?

GitHub Actions builds and deploys the repository to GitHub Pages — buildless by design, per ADR-0002. Every deploy runs the CI guards (category completeness, theme toggle, lightbox and mobile-nav behaviour) before the site goes live, so a broken change can't ship silently.

Why do you keep a changelog at all?

Because the whole point of the site is real work, not demos. A dated, traceable record means you can see exactly how the tracker has evolved — and verify any claim here against the repository history.
