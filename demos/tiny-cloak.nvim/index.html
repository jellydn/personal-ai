Neovim plugin

Share the buffer, not the secret.

tiny-cloak.nvim masks sensitive values in `.env`, JSON, and YAML files. It uses Neovim extmarks, so the file content remains unchanged while the buffer stays safe to present.

View source on GitHub ↗Installation
.env — Neovim
# buffer display
API_KEY=****************
SECRET_TOKEN=**************
DATABASE_URL=************************

i → reveal while editing
Esc → cloak again

Safe by default, editable when needed.

Common credential names and configuration formats work without setup. Toggle or configure the plugin when a buffer needs different rules.

Mask common keys

`API_KEY`, `SECRET`, `PASSWORD`, `TOKEN`, `CREDENTIAL`, and `AUTH` are recognised.

Keep file content intact

Extmarks change the display only; no values are replaced on disk.

Reveal while editing

Enter insert mode to inspect a value, then leave it to cloak again.

Install with lazy.nvim

{
  "jellydn/tiny-cloak.nvim",
  event = { "BufReadPre", "BufNewFile" },
  opts = {},
}
