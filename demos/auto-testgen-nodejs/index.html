AI developer workflow

Tests, generated from the function out.

auto-testgen-nodejs is a focused example of using Pythagora to turn a TypeScript or Node.js function into a starting set of unit tests.

View source on GitHub ↗See the workflow
auto-testgen-nodejs
$ npx pythagora --unit-tests \
  --func divide --path src/math.ts

✓ Analysed src/math.ts
✓ Generated divide.test.ts
  Review, refine, and run the tests.

Keep the developer in the loop.

Generation removes repetitive setup. Review still decides whether the test cases express the required behaviour.
