Neovim plugin

A terminal that stays out of your way.

tiny-term.nvim provides floating and split terminal windows for Neovim 0.11+. It is small, dependency-free, and compatible with the familiar `Snacks.terminal` API shape.

Terminal management with a small surface area.

Open a shell, run a command, select a window style, and return to your editing flow.

Float or split

Choose a floating terminal or a bottom, top, left, or right split.

Stable terminal IDs

Commands, working directories, environments, and counts identify terminal instances.

Drop-in API shape

Use `toggle()`, `open()`, `get()`, and `list()`, or override `Snacks.terminal`.

Install with lazy.nvim

{
  "jellydn/tiny-term.nvim",
  opts = {},
}

require("tiny-term").toggle()
