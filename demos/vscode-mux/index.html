VS Code extension

Your workspace. Your persistent terminal.

vscode-mux opens VS Code terminals inside tmux or zellij. Each workspace gets a predictable session, so panes and running processes stay available between terminals.

VS Code / CodeMux
$ code .
Open terminal → CodeMux profile

✓ tmux session: personal-ai
✓ attached to existing session

$ npm run dev

One terminal flow across editor windows.

CodeMux makes the multiplexer the terminal default instead of an extra manual step.

Open a terminal

CodeMux selects tmux or zellij from your extension settings.

Reuse the workspace session

The first terminal creates it; later terminals attach to it.

Keep working

Close and reopen a terminal without losing the running session.

Requirements

$ brew install tmux   # or: brew install zellij
$ code --install-extension jellydn.vscode-mux
