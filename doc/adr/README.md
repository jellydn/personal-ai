# Architecture Decision Records

This directory records the significant architecture decisions for **personal-ai** — the
portfolio tracker and its marketing showcase.

Each ADR captures the context, the decision, and the consequences (positive and negative)
so future contributors understand *why* the code is shaped the way it is.

| ADR | Title | Status |
|-----|-------|--------|
| [0001](0001-buildless-static-site.md) | Buildless static architecture | Accepted |
| [0002](0002-github-pages-repo-root-deploy.md) | GitHub Pages repo-root deployment | Accepted |
| [0003](0003-vendored-favicons-showcase.md) | Self-contained showcase with vendored favicons | Accepted |
| [0004](0004-progressive-enhancement.md) | Progressive enhancement for performance and motion | Accepted |

## Adding a new ADR

1. Copy an existing ADR (e.g. `0004-progressive-enhancement.md`) as the next number (`0005-...`) and follow its structure.
2. Fill in Status, Context, Decision, and Consequences.
3. Add a row to the table above.
